# Can We Make it?

Can We Make it? is a 2D physics-based climbing prototype made in Unity. You play as a rolling ball with a grappling hook and must climb upward through a vertical obstacle course by attaching, retracting, and swinging between platforms.

## Gameplay
The goal is to reach the top of the course as quickly as possible. Mistakes can send you falling back down, so momentum, timing, and precision matter.

## Features
- Physics-based rolling movement
- Grappling hook traversal
- Rope extension and retraction
- Timer and best-time tracking
- Pause, reset, and replay systems
- Audio and particle effects
- URP 2D lighting and shadows

## Controls
- **A / D** — Move
- **Space** — Hook / detach
- **Left Click** — Retract rope
- **Right Click** — Extend rope
- **Esc** — Pause
